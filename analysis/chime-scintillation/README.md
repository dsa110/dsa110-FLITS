# Legacy CHIME scintillation experiments

This directory retains dated diagnostic and documented-failure experiments.
It is not the current campaign index and does not define the present sample-wide
measurement roster.

Current finalized campaign products live under
[`analysis/window-tuning-campaign-2026-07-17/results/`](../window-tuning-campaign-2026-07-17/results/).
That campaign contains one qualified high-resolution CHIME record
(`chromatica_hi`) and 23 diagnostic-only records.

The former zero-measurement inventory and its machine-readable
`INVENTORY.yaml` were moved, without deletion, to
[`.archive/outdated-science/2026-07-17/analysis/chime-scintillation/`](../../.archive/outdated-science/2026-07-17/analysis/chime-scintillation/).
The experiment directories here remain valid historical negative evidence.
