## Learnings

- `all_pairs_cross_acf` currently delegates to `blockwise_cross_acf_pairs` by building an explicit list of pairs. For 2 polarizations and 15 on-pulse time samples, this is ~435 pairs. A single call on 23,064 channels and 40 lags takes roughly 30 seconds, so the full 128-trial/cell calibration campaign is impractical without vectorization.
- The `normalizations` parameter is necessary for off-pulse nulls. When the input is the baseline-subtracted residual (`dynamic - baseline`), the off-pulse mean is near zero, so the per-fold norm would be near zero and the ACF would diverge. Passing the on-pulse envelope per fold as the normalization keeps the off-pulse ACF near zero and the on-pulse ACF at the correct amplitude.
- One off-pulse template is not enough to remove the instrumental nuisance. The off-pulse ACF itself has a coherent positive/negative lag structure, and the on-pulse residual after removing it still has `dnu` pinned to the lower bound.
- The `fit_cross_lorentzian` return dictionary currently does not include `r_val` / `p_val` (contrary to the previous session summary). It returns `dnu_mhz`, `dnu_err_mhz`, `m`, `m_err`, `amplitude`, `constant`, `redchi`, `n_fit_points`, `fit_lags_mhz`, `observed_acf`, and `model_acf`. If Pearson correlation metrics are needed, add them explicitly.
- B4 failed on the same data at the injection-recovery gate, so the C1 result is not obviously worse than B4, but it is not yet good enough to unblind.
