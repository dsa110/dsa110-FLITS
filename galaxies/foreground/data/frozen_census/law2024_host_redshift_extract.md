# Law et al. 2024 host-redshift source extract

Minimal source-bearing extract for the three co-detections that predate the
Verdi sample. Source: Law et al. (2024), “Deep Synoptic Array Science: First
FRB and Host Galaxy Catalog,” Astrophysical Journal 967, 29,
DOI `10.3847/1538-4357/ad3736`, arXiv `2307.03344v2`, Table 3.

The paper states that every host redshift was measured spectroscopically from
at least three emission lines. Table 3 reports the exact values frozen here.
The existing census values are rounded archival values. The CSV records both;
no value is inferred or silently replaced.
